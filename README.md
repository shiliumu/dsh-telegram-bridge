# @local/dsh-telegram-bridge

把一个 DSH 会话桥接到你自己的 Telegram Bot。本插件是针对当前安装的 DeepSeek Harness（0.2.0-rc.2）的实际 API 全新实现的，**没有**复用 `@sympoies/dsh-telegram` 的代码（该包面向旧版 API，直接套用会有兼容性问题）。

## 功能

1. **会话内开关**：任意会话的「…」菜单里有「Telegram 桥接…」选项；会话输入框下方有常驻面板（点击展开）。
2. **消息转发（DSH → Telegram）**：启用后，该会话的用户消息与助手回复会推送到所有被放行发送者所在的 Telegram 聊天。
3. **放行注入（Telegram → DSH）**：给 Bot 发过消息的 Telegram 用户/群聊会全部出现在面板的发送者列表里（含用户名与 id）；勾选**放行**后，其消息正文原样注入会话队列，由 Agent 处理；最近一条消息的来源显示在面板中，不会混入模型正文。未放行的用户仅被记录，消息不进入会话。
4. **提问桥接**：Agent 通过 `ask_user_question` 提问时，问题会推送到 Telegram（内联键盘点选 / 直接回复文本），与 DSH 界面并行，先到先得。
5. **无需绑定**：没有绑定码/绑定流程——发消息即出现在面板，勾选放行即双向互通。

## 使用步骤

1. 在 BotFather 创建一个 Bot，拿到 Token（形如 `123456:ABC-DEF…`）。
2. 打开目标会话 → 输入框下方点「✈ Telegram」展开面板。
3. 粘贴 Token 并保存（Token 存入凭据服务，**不会**写入会话日志）。
4. 点「启用转发」。
5. 让协作者在 Telegram 里向你的 Bot 发消息（发 `/start` 即可）→ 他们自动出现在面板的发送者列表。
6. 勾选「放行」想接入的人/群 → 此后：会话消息转发到其聊天；其回复进入会话；Agent 的提问可在 Bot 上作答。

会话里也可以用斜杠命令：`/tg on`、`/tg off`、`/tg allow <发送者ID>`、`/tg disallow <发送者ID>`、`/tg status`。

## 状态归属（设计说明）

| 状态 | 存放 | 重启后 |
|---|---|---|
| 启用开关、放行名单 | 会话日志（`/tg` 命令事件，由 `telegramBridge` 投影折叠） | 恢复（fork/resume 同样继承） |
| Bot Token | 凭据服务，每会话一个 ref | 恢复 |
| 发送者/聊天名录 | 存储域 `telegram_bridge` | 恢复 |
| 轮询循环、待答问题 | 运行时内存 | 重建 |

## 限制

- 消息流转要求会话处于「已打开」状态（本次启动后打开过）。重启 DSH 后，先打开一次会话再使用；冷会话收到消息时 Bot 会提示。
- 同一个 Bot Token 被多个 DSH 实例同时轮询会 409 冲突——面板会显示错误，请只保留一个实例。
- 问答桥接仅在「已启用 + 至少一位创作者 + 已绑定聊天」时接管；否则问题只在 DSH 界面回答。
- 转发内容：纯文本（用户/助手消息），不含工具调用、图片与附件。
